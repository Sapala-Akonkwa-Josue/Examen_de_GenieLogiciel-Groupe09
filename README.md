# Examen de Génie Logiciel - Groupe 09

## Présentation

Ce projet est une application Windows Forms développée en C# dans le cadre du cours de Génie Logiciel. Elle illustre les principes fondamentaux de la conception logicielle, incluant la modularité, la réutilisabilité des composants et la gestion des données.

## Structure du Projet

- **1.Classes** : Classes métier représentant les entités de l'application.
- **2. Users Controls** : Contrôles utilisateur personnalisés pour l'interface graphique.
- **3. Forms** : Formulaires principaux de l'application.
- **4. Connexion** : Gestion de la connexion à la base de données.
- **ScriptDB** : Scripts SQL pour la création de la base de données.

## Technologies Utilisées

- C#
- .NET Framework
- Windows Forms
- SQL Server
- Visual Studio
